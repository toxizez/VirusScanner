# 🛡️ Virus Scanner Pro

![Version](https://img.shields.io/badge/version-2.0-green)
![Platform](https://img.shields.io/badge/platform-Windows-blue)
![License](https://img.shields.io/badge/license-MIT-yellow)

Красивая программа для проверки файлов на вирусы, написанная на Batch.

## ✨ Возможности

- 🔍 **Быстрая проверка папки** — сканирование выбранной директории
- 🎯 **Проверка файла** — детальный анализ конкретного файла
- 💻 **Полная проверка системы** — проверка системных папок
- 📊 **Информация о системе** — детальные сведения о ПК
- 🎨 **Красивый интерфейс** — ASCII-графика, цвета, анимация
- ⚡ **Эвристический анализ** — проверка расширений и имён файлов

## 🚀 Установка

1. Скачайте файл `VirusScanner.bat`
2. Поместите его в любую папку
3. Запустите от имени администратора

## 📖 Использование

```cmd
VirusScanner.bat
```

Выберите нужный пункт меню:

| Пункт | Описание |
|-------|----------|
| 1 | Быстрая проверка папки |
| 2 | Проверка конкретного файла |
| 3 | Полная проверка системы |
| 4 | Информация о системе |
| 5 | Выход |

## 🎨 Цветовая схема

- 🟢 Зелёный — безопасно
- 🟡 Жёлтый — подозрительно
- 🔴 Красный — угроза
- 🔵 Синий — информационный

## ⚠️ Важно

> **Это демонстрационная программа!** Она использует эвристический анализ
> (проверку расширений и имён файлов), а не реальную базу вирусов.
> Для настоящей защиты используйте антивирусы: Kaspersky, ESET, Windows Defender.

## 📋 Требования

- Windows 7/8/10/11
- Права администратора
- UTF-8 совместимый терминал
